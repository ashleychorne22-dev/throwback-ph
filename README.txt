THROWBACK PH — ONLINE PHOTO EDITION (November 2026)

1. Double-click index.html in an internet-connected browser.
2. Scroll through the lobby, 3 galleries, comparison hall, Fashion & Ads Wall, and source list.
3. All 38 exhibit image slots are linked to real public photos/media on Wikimedia Commons (they are not in this ZIP).
4. Click the photographer/source below each exhibit to see the original Wikimedia Commons page and license.
5. Every image card tries two public alternative addresses if the initial image fails; if all fail, a visible original-source link appears instead of a blank box.
6. Image host hotlinking restrictions, connectivity and removal by third parties cannot be controlled by the museum. If needed open the credited source directly.
7. Some photographs are later than the era they help illustrate; see the context text under each exhibit.
